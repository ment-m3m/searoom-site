# searoom-site

iPhone向け匿名SNS **SEAROOM** の公開サイト（紹介・サポート・プライバシーポリシー）。

- `index.html` … 紹介・サポート窓口
- `privacy.html` … プライバシーポリシー

App Store の申請に必要な「サポートURL」「プライバシーポリシーURL」を提供するための、
**静的HTML 2枚だけ**のリポジトリです。GitHub Pages（main / ルート）で公開しています。

アプリ本体のソースコードは別のプライベートリポジトリで管理しています。

## 更新の仕方

正本はアプリ側リポジトリの `web/` にあります。
そちらを直してから、このリポジトリへコピーして push してください。
